# SaaS-Customer-Churn-Retention-Dashboard
An overall SaaS churn analysis project with customer behavior, churn patterns, and potential revenue risk.

🔎 Key findings:
• Overall churn rate: 42.34%
• Monthly churn: 48.36% vs 29.25% for annual customers
• Low product usage showed the highest observed churn
• Newer customers showed higher observed churn
• Low product usage was the most frequently recorded churn reason

💡 Recommendations:
• Strengthen onboarding for new customers
• Monitor product engagement as an early-warning signal
• Prioritize high-value at-risk customers
• Explore annual-plan conversion strategies

Tools: MySQL | SQL | Power BI
